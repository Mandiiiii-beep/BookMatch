# BookMatch

Discover your next favorite book & find used copies at great prices.

A small showcase project: pick a genre, browse 12 books pulled live from the
[Open Library API](https://openlibrary.org/developers/api), and jump to AbeBooks
to hunt for used copies. No API key, database or login required.

![BookMatch screenshot](docs/screenshot.png) <!-- TODO: add a screenshot -->

## Tech stack

- [Next.js](https://nextjs.org) (App Router, route handler) + React
- TypeScript
- Tailwind CSS
- Open Library Subjects & Covers APIs
- Deployed on Vercel

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
